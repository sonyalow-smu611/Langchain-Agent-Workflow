# Attention Mechanism Cheatsheet

## Key Ideas
- Transformers utilize attention over RNNs for enhanced parallel processing.
- Attention is the core concept of transformers.
- Multi-head attention enhances the model's ability to recognize both short and long-range dependencies within text.

## Definitions
- **Attention**: A mechanism that decides how much each value vector contributes to the output, influenced by the similarity between query and key vectors.
- **Self-Attention**: A process where tokens in the same input sequence attend to each other, allowing the model to understand the relationships within the same context.
- **Multi-Head Attention**: A technique where multiple attention heads run in parallel, capturing a diverse set of relationships in the input data.
- **KV Cache**: A storage component that keeps track of attention information from previous tokens during sequence generation, facilitating efficient processing.

## Formulas/Rules
- **Attention Scores**: Typically calculated using dot product or scaled dot product between query (Q) and key (K) vectors.
  
  \[
  \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
  \]
  
  Where:
  - \(Q\) = Query vector
  - \(K\) = Key vector
  - \(V\) = Value vector
  - \(d_k\) = Dimension of key vectors (used for scaling)

- **Weight Contribution**: Higher similarity between query and key leads to a higher contribution of the corresponding value vector in the output.

## Memory Cues
- **Transformers & Parallelism**: Think of "Transformers" with "wings" representing speed and efficiency in processing (parallelism).
- **Self-Attention**: Visualize a group discussion where everyone is listening to each other.
- **Multi-Headed Attention**: Imagine multiple pairs of eyes looking at different perspectives on the same topic.
- **KV Cache**: Picture a notepad where you jot down previous discussions to avoid repetition and maintain context.
