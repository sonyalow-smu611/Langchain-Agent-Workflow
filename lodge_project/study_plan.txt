# API Calling Cheatsheet

## Key Ideas
- APIs enable software communication.
- Commonly used for data retrieval and manipulation.
- Security and usage limitations are important considerations.

## Definitions
- **API (Application Programming Interface)**: A set of protocols that allow applications to communicate.
- **Endpoint**: The specific URL for accessing an API function.
- **HTTP Methods**: Operations used in API calls:
  - **GET**: Retrieve data.
  - **POST**: Send data to create a resource.
  - **PUT**: Update a resource.
  - **DELETE**: Remove a resource.
- **Request**: The call made to the API (includes method, endpoint, headers, body).
- **Response**: Data returned by the API, typically in JSON or XML.
- **Authentication**: Methods (API keys, OAuth, JWT) to secure API access.
- **Rate Limits**: Restrictions on the number of requests within a certain timeframe.

## Important Rules
1. **Know Your Endpoints**: Familiarize yourself with available endpoints.
2. **Use Correct HTTP Methods**: Match method to operation.
3. **Handle Errors Gracefully**: Prepare for error responses (e.g., 404, 500).
4. **Read Documentation**: Refer to API docs for specifics on usage.

## Example API Call Breakdown
### URL Endpoint
- Base: `https://api.weatherapi.com/v1/current.json`
- Key: `?key=YOUR_API_KEY`
- Query: `&q=London`

### JavaScript Fetch Example
```javascript
fetch('https://api.weatherapi.com/v1/current.json?key=YOUR_API_KEY&q=London')
    .then(response => response.json())
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.error('Error:', error);
    });
```

## Response Format Example
```json
{
    "location": {
        "name": "London",
        "country": "UK"
    },
    "current": {
        "temp_c": 15,
        "condition": {
            "text": "Partly cloudy"
        }
    }
}
```

## Memory Cues
- **API = Application -> Interaction**: Think of APIs as bridges for software.
- **GET your data, POST new things**: Remember the actions of HTTP methods by their initials.

### Conclusion
Mastering API calls involves construction of requests and interpretation of responses. Familiarize yourself with endpoints, methods, and error handling to effectively utilize APIs.
